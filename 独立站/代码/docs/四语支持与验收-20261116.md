# 独立站四语支持与验收

日期：2026年11月16日。状态：本地实现与自测完成，等待母语术语审校及业务验收。

## 使用规则

- 默认语言为格鲁吉亚语（ka）；首次访问根路径 / 会进入 /ka。
- 支持格鲁吉亚语、俄语、英文、中文。明确的 /ka、/ru、/en、/zh 链接优先于浏览器保存的偏好；根路径记住用户主动选择的有效语言，非法偏好回退ka。
- 切换语言保留当前页面、车辆ID、筛选与排序参数，并同步详情返回列表的语言。收藏、最近浏览、市场、币种和车辆数据不因语言切换而改变。
- 导航、首页、筛选与详情、收藏、公司与服务、合作与联系、说明页、弹层、错误提示及摘要生成均已接入。文档lang、页面标题、简介与跳转链接同步切换。
- 后台界面继续为中文，新增格鲁吉亚语／俄语车型名称和描述字段。名称缺译优先使用英文，描述缺译优先英文再中文，并提示显示已有内容，不自动翻译或改写业务数据。
- 现有数据无需迁移。新增字段为空时正常回退；旧客户端未传新增字段时保留已有值，明确传空字符串才能清空。

## 维护入口

- src/translations.js：307条文案映射，含格鲁吉亚语和俄语。
- src/i18n.js：默认语言、偏好、路由切换与车辆内容回退。
- src/app.js、src/data.js：页面、品牌与市场；型号及品牌保留通用拉丁字母名称。
- admin/admin.js、backend/store.mjs：多语言内容输入、校验和保存。

中文车型名与中文描述仍沿用现有必填规则，新增字段可选。车辆价格、库存、汇率与售卖状态不由翻译逻辑调整。GEL仍为固定演示换算。

## 验证

- npm test：10组通过，覆盖默认语言／保存偏好／显式路由优先级、翻译键覆盖、换行标签、路由与返回条件、四语搜索和内容回退；后台验证格俄字段重启保留及旧请求不会擦除。
- npm run build 与脚本语法检查通过。
- 实际浏览器：根路径首次进入/ka；切俄语后再次根路径进入/ru；俄语品牌＋能源筛选返回A06；详情切格语后返回链接保留brand与energy条件；原中英文切换正常。
- 1280像素桌面首页已查看截图；390像素手机菜单切换及两种语言各10个核心页面已检查，未发现横向溢出、undefined或主要内容的中文界面残留。控制台检查无warning/error。

## 2026-11-16 管理端四语补齐（N05 / G06）

后台登录、列表、编辑、上传状态和常见接口错误支持格语、俄语、英语、中文，首次默认格语。右上角可切换，后台偏好独立保存在本机浏览器；URL的lang参数优先。切换保留未保存名称、描述、数值、勾选和图片顺序。名称至少填一种语言，上架描述至少填一种语言，不强制中文，不自动翻译。

本地12组测试及构建通过；HTTP测试验证四种语言各自单独发布、空名称/空描述拒绝、原有权限和版本冲突。隔离浏览器验证默认格语登录、英文登录、英→俄→中→格切换保留表单和上传图片、格语单语上架并重新编辑。390px视口无页面横向溢出，检查期间控制台无warn/error。测试数据未写入用户运行目录。系统文件选择器、原生日期弹窗语言由浏览器/系统决定。格俄译文待母语业务人员审校；会话过期恢复路径已实现但本轮未手工等待8小时验证。
