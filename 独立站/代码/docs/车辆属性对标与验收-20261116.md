# 车辆配置、车况和资料状态对标

日期：2026-11-16。N05/G06。参考为MYUCAR公开车辆详情，未访问其管理端，不推断其后台字段或核验流程。

参考：https://www.myucar.com/zh/vehicles/2026-宝马-宝马x5-cn-na-261116-c2903e

现场看到该样本分为车辆参数、车况描述、主要配置、资料状态。参数包含制造时间、马力、排量、驱动与颜色；配置有巡航、影像、方向盘、天窗、导航、灯光、座椅和无钥匙进入；资料包括行驶证、登记证书、铭牌、钥匙数量、维保、检测与出险记录。观察这些展示不等于核实其实际车辆或文件。

原站点缺口：Starlink仅有价格、年月、里程、能源、车身、座位、变速箱和描述。前台资料区为固定“待提供”，后台不能逐项维护。

本轮实现41个扩展字段：

| 组 | 字段 |
| --- | --- |
| 补充参数（10） | 款型、首次登记年月、马力、排量、驱动、左右舵、颜色、电池容量、纯电续航、续航标准 |
| 主要配置（14） | 定速/自适应巡航、倒车/360影像、多功能方向盘、天窗、导航、LED灯、真皮座椅、无钥匙进入、座椅加热/通风、电动尾门、车道保持 |
| 车况历史（8） | 事故、泡水、火烧、补漆、结构维修、过户次数、电池SOH、检测日期 |
| 资料状态（9） | 钥匙数量、行驶/注册凭证、登记/所有权文件、铭牌、维保、检测、出险、出口、清关 |

配置可选待确认/配备/未配备；车况记录待确认/有/无；资料待确认/已提供/未提供/不适用。数字空值与0分开。旧数据不自动填“无事故”或“已提供”，旧接口请求未带attributes时保留已有扩展信息。所有字段可后续补齐，不因历史信息缺失阻止已有车辆编辑。价格、年月和发布规则保持原状。

数据统一存储attributes，字段和枚举共享定义供后端校验、后台表单和前台详情使用。所有标签和枚举中英格俄四语显示，保存语言无关编码，不生成多份相互冲突的数据。款型为管理员原文，若需四语解释可使用既有四语描述；本轮不新增自动翻译。文件“已提供”是商家录入状态，不是平台核验；资料附件和证件原件并未新增公开上传或下载功能。

验证：17组测试通过，构建和差异检查通过；包括非法枚举、数字范围、真实日期、文本转义、空/0区分、旧请求保留、保存与重启持久化。隔离浏览器录入天窗、倒车影像、资料状态、钥匙数及SOH，换俄语保留，保存后再打开与前台一致；格俄英390px详情无横向溢出，控制台无警告错误。测试未改动用户车源数据。

交付：src/vehicle-attributes.js、admin表单和采集、backend/store.mjs、前台详情及tests/vehicle-attributes.test.mjs。截图docs/screenshots/车辆属性-管理端资料.png。状态：本地已实现并自测，尚未提交推送或部署，测试服务器仍为9d0bd12。下一步结合用户业务确认配置清单与资料口径，再发布测试环境；母语专业审校待完成。

## 商品页精简展示修订

按用户反馈，前台不再逐项列出空白或待确认字段，空分组隐藏；主要配置仅把present项目显示为带勾选标记的名称标签，不显示absent或unknown。后台仍提供完整录入字段。明确填写的车况有/无、资料未提供/不适用及数字0保留，避免隐藏已披露的有效信息；空车辆描述也隐藏标题。四语规则一致。

再次查看MYUCAR同一公开样本：主要配置直接列出配置名，资料区仍有未提供项。我们采纳配置名称展示，并按用户要求额外隐藏未录入资料。18组测试及构建通过，隔离浏览器确认仅4个已配备标签、3个已填资料项目，空参数和车况组隐藏；未修改真实车源。本修订为本地变更，尚未推送部署。
