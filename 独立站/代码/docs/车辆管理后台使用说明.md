# Starlink 车辆管理后台

2026年11月16日。本次新增代码与本地验证完成，待业务验收；未部署。

## 启动与登录

需要Node.js 20及以上，无需安装第三方依赖。在代码目录运行：

```sh
npm run admin:setup
npm run dev
```

第一条命令交互设置 `admin` 密码，12至128字符，输入不回显；密码仅保存加盐scrypt哈希。没有默认密码。启动后访问 `http://127.0.0.1:5188/admin`。更改密码时先正常停止服务，再运行设置命令；重启后原登录会话失效。若异常退出留下锁文件，可先启动并正常停止服务以自动清理失效进程锁，不要在服务仍运行时手工删除锁。

会话有效期8小时，仅保存在服务进程内；服务重启须重新登录，车辆数据不受影响。前台默认 `/ka`，也支持 `/ru`、`/en`、`/zh`。本地验证使用临时目录与临时测试账号，未设置你的正式管理员密码，也未将测试商品导入正式目录。

## 录入与发布

1. 点击“新增车辆”，填写品牌、车型名称、美元价格、年月、里程等。当前品牌范围为比亚迪、长安、岚图、极氪。
2. 上传照片：JPEG、PNG、WebP，单张最多8MB、每车最多20张。左右箭头调整顺序，第一张是封面；“移除”解除这辆车与图片的关联，保存后生效。
3. 可填写中文、英文、格鲁吉亚语、俄语车型名称和描述；名称至少一种，发布时描述至少一种。换行保留，不执行HTML。缺译读取已有内容，按当前语言、英文、中文、格语、俄语回退，不自动翻译或复制到空字段。
4. 可勾选“首页推荐”。只有演示数据才勾选“演示样本”；原8条样本已标记。
5. 选择状态并保存：草稿和已下架仅后台可见；已上架进入前台列表与详情。上架要求至少一种语言的描述、有效年月、至少一张图片；其他关键数值与选项同时校验。
6. 修改后点击保存，前台刷新或重新导航时读取最新数据。下架后再次打开详情不再展示；已打开页面不会远程即时推送刷新。

车辆编号由系统自动生成，不随编辑变化。后台保留已下架记录，可重新上架，不提供永久删除。两个窗口同时编辑时，旧版本保存会被拒绝，需重新加载再编辑，避免覆盖另一窗口的修改。离开未保存表单时有提示。

## 数据与运行方式

- `var/catalog.json`：车辆资料、版本与发布状态。
- `var/uploads/`：上传图片，随机文件名；未关联或被移除的文件暂时保留，避免误删被其他车辆引用的图片。
- `var/admin.json`：管理员密码哈希，不对外提供静态访问。
- `var/server.lock`：运行进程锁，防止同一目录被两个服务进程同时写入。

默认数据目录位于代码根目录下，不随构建清理。可通过 `STARLINK_DATA_DIR=/绝对路径` 指定独立持久目录；设置密码和启动服务须使用同一个目录。首次启动没有catalog时才导入8条演示样本；后续启动不会覆盖已维护车源。数据损坏时拒绝启动，不自动覆盖。

`npm run build` 生成包含前台、后台与服务代码的 `dist/`，使用 `node dist/server.mjs` 启动，不再是纯静态部署。不要同时运行源码服务与构建服务指向同一数据目录。数据目录不纳入Git。

当前存储适用于单进程、小规模目录维护：同步JSON原子替换写入，图片保存在本机磁盘；不支持多服务器共享写入。需要多运营账号、多人权限、修改审计、大规模车源或多实例部署时，应增加相应权限与数据库／对象存储方案。

## 备份与正式部署边界

备份时先停止服务，复制完整数据目录，包含catalog、uploads及密码哈希；按敏感数据保护备份。恢复到空数据目录后再启动验证车源和图片。当前没有定时备份、磁盘配额或自动清理未使用图片；需在部署运维阶段落实。

本地默认仅监听127.0.0.1。正式HTTPS反向代理环境设置 `COOKIE_SECURE=1`，代理保留外部Host，保证页面与API同源；上传请求体限制须允许8MB图片。不要通过公开静态目录暴露var。接口使用HttpOnly／SameSite Cookie、同源检查、CSRF校验、登录尝试限流、输入校验和静态文件白名单。生产安全、备份恢复及HTTPS仍需随实际部署验收。

USD是录入基础币种；GEL仍使用演示固定汇率。真实报价、图片使用权及公开联系渠道须由业务方确认。后台不包含询盘接收、支付或物流功能。

## 2026-11-16 管理端四语补齐（N05 / G06）

后台登录、列表、编辑、上传状态和常见接口错误支持格语、俄语、英语、中文，首次默认格语。右上角可切换，后台偏好独立保存在本机浏览器；URL的lang参数优先。切换保留未保存名称、描述、数值、勾选和图片顺序。名称至少填一种语言，上架描述至少填一种语言，不强制中文，不自动翻译。

本地12组测试及构建通过；HTTP测试验证四种语言各自单独发布、空名称/空描述拒绝、原有权限和版本冲突。隔离浏览器验证默认格语登录、英文登录、英→俄→中→格切换保留表单和上传图片、格语单语上架并重新编辑。390px视口无页面横向溢出，检查期间控制台无warn/error。测试数据未写入用户运行目录。系统文件选择器、原生日期弹窗语言由浏览器/系统决定。格俄译文待母语业务人员审校；会话过期恢复路径已实现但本轮未手工等待8小时验证。

交付物：admin/admin.js、admin/i18n.js、admin/messages.js、backend/store.mjs、tests/admin-i18n.test.mjs；截图位于docs/screenshots/后台四语-格语编辑.png和后台四语-手机.png。此次修改尚未提交或推送。下一步：用户试用并确认术语；业务验收以实际新增、上传及上架为完成条件。
