# Starlink 独立站与车辆管理后台

前台参考MYUCAR布局，企业内容来自用户提供的《Starlink集团.pdf》。已实现车辆管理后台和持久化接口，当前为本地开发成果，尚未部署。

## 本地运行

Node.js 20及以上，无第三方运行依赖，无需npm install。

```sh
cd /Users/zhenghao/workspace/caucasia/独立站/代码
npm run admin:setup
npm run dev
```

首次运行第一条命令设置管理员密码，输入不回显，没有默认密码。账号为 `admin`。

- [网站首页](http://127.0.0.1:5188/)
- [管理后台](http://127.0.0.1:5188/admin)
- [后台使用、备份与验证说明](docs/车辆管理后台使用说明.md)

默认仅监听本机，结束按Ctrl+C。改端口可用 `PORT=5190 npm run dev`。

## 已实现

前台：首页、品牌与条件筛选、排序、详情图库、收藏及最近浏览、企业介绍、售后服务、区域合作、咨询摘要、格鲁吉亚语／俄语／英文／中文及响应式布局。前台读取后端已上架车源；接口失败显示重试，不回退到静态演示数据。

后台：管理员登录，新增和编辑车辆，四语车型名称与描述，价格、年月、里程、能源、车身、座位和变速箱参数，多图上传、排序及封面，草稿、上架、下架，首页推荐、搜索和状态筛选。支持资料中的四个品牌，新增品牌需扩展配置。

车辆与图片存到服务器磁盘，重启保留。使用单进程目录锁、JSON原子替换写入及版本冲突校验；多窗口旧版本不能覆盖新修改。管理员密码采用加盐scrypt哈希，使用HttpOnly Cookie、同源及CSRF校验和登录限流。

## 构建与测试

```sh
npm test
npm run build
node dist/server.mjs
```

构建产物现在包含Node服务、前台和后台，不能只做静态托管或直接打开HTML。源码和dist默认共用代码根目录下的 `var/` 数据，构建不会复制或清理var。可用 `STARLINK_DATA_DIR` 指定独立绝对路径，设置密码和启动须指向同一路径。不能同时启动两个服务写同一数据目录。

## 数据及功能边界

- 首次启动导入8条明确标记的演示车源，后续不会覆盖维护的数据；请通过后台录入真实车辆并下架样本。
- 参考车辆图片仅供本地复原，发布前需替换自有或获授权图片。公司Logo与企业照片来自PDF，来源见[内容与素材来源](docs/内容与素材来源.md)。
- 价格以USD保存；GEL仍使用固定演示汇率1 USD = 2.7 GEL。实际费用和交付条件需业务确认。
- 公司公开电话、邮箱和详细地址待补；咨询目前只生成本地摘要，没有发送或落库。
- 后台为单管理员、小规模单进程版本，不包含客户登录、支付、物流、多角色权限、操作审计和自动备份。正式部署与恢复验收另排。

## 语言

默认格鲁吉亚语，支持ka／ru／en／zh四语；根路径记住主动选择，显式语言链接优先。后台可填写格鲁吉亚语和俄语车型名、描述；缺译回退英文或中文。新译文待母语术语审校，详见[四语支持与验收](docs/四语支持与验收-20261116.md)。

后台同样支持格鲁吉亚语（默认）、俄语、英语、中文，可在登录页和后台顶部切换。车型名称、描述各自按语言维护，名称至少一种，发布描述至少一种；缺译展示已有内容，不自动翻译。详见后台使用说明。
