# 高加索汽配项目

本仓库在同一个 `main` 分支维护两个独立应用，按文件夹区分：

| 应用 | 代码目录 | 本地端口 |
| --- | --- | --- |
| 汽配采购 Demo | [poc/汽配demo](poc/汽配demo/README.md) | 5173 |
| Starlink 独立站与车辆后台 | [独立站/代码](独立站/代码/README.md) | 5188 |

两个应用各自运行，不共用运行数据。独立站后台位于 `/admin`，首次启动前在其代码目录运行 `npm run admin:setup` 自行设置密码；仓库不包含管理员密码、车源运行数据、用户上传图片和公司原始PDF。

## 运行汽配 Demo

在项目根目录执行：

```sh
cd poc/汽配demo
npm run dev
```

打开 `http://127.0.0.1:5173`。测试、文案工具及 Docker 部署命令也在 `poc/汽配demo/` 目录中执行，详见该目录的 README。

## 运行独立站

```sh
cd 独立站/代码
npm run admin:setup
npm run dev
```

打开 `http://127.0.0.1:5188/zh`，后台为 `http://127.0.0.1:5188/admin`。仅本地开发启动，不代表已部署。

若同时使用汽配Demo的Docker运行方式，请设置 `CAUCASUS_PORT=5189`，避免与独立站默认5188端口冲突。
